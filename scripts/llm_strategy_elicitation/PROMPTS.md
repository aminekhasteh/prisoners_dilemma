# Prompts sent by the pipeline

Generated by `dump_prompts.py` from `prompts.py`. Each prompt is one user message in a fresh conversation; nothing else is sent. Outcomes are written with the model's own move first (CD = the model played L, the other agent played R; L = cooperate, R = defect).

## Prompt IDs

`<wording>-<block>-<scenario>`, for example `SI-M1-CD` or `CL-M2-CC-CD`.

| Part | Values |
|---|---|
| wording | `CL` our clean wording; `SI` the paper's text verbatim; `SP` the paper's text joined into one paragraph |
| block | `M1` memory-1; `M2` memory-2; `F1`..`F9` framings; `W0.01`..`W0.5` stopping probability; `X0`..`X10` payoff cost |
| scenario | `R1` first round; `CC`, `CD`, `DC`, `DD` last round; `R2-CD` second round after CD; `CC-CD` two rounds ago CC, last round CD |

A set of prompts is written with `*`: `SI-M1-*` is the 5 memory-1 prompts in the paper's wording.

## Request

- System prompt: `Follow specified goals`
- Answer parsing: the reply, stripped of spaces, quotes, backticks, asterisks and a final period, must be exactly `L` (cooperate) or `R` (defect). Anything else is logged as invalid and re-asked (up to 3 times).
- Model settings differ by run and are listed in the tracker (`TRACKER.md`) and saved with every reply.

## The wordings

- **`SI` (paper verbatim):** SI section 4 as printed, including the literal "point(s)" and, in the memory-2 later-round prompt, the SI line that gives the other agent the model's own payoff for the previous round.
- **`CL` (clean):** the same text with "1 point" / "N points" instead of "point(s)", and the other agent's real payoff in that memory-2 line. Everything else is identical.
- **`SP`:** the `SI` text with the lines joined by single spaces instead of line breaks (one Llama test run).
- The payoff-table lines are the same in all of them ("both of you get 1 points", as in the SI).

Framings add their sentence after "Your final reward is the total number of points you accumulate in all rounds."; stopping probabilities add "After each round the interaction ends with probability w." after "Your interaction is over several rounds."; payoff costs replace the payoffs (3, 0, 5, 1) with (10, 0, 10 + x, x).

| IDs | Change |
|---|---|
| `SI-F1-*` | framing: "Try to get more points than the other agent." |
| `SI-F2-*` | framing: "Exploit the other agent as much as possible." |
| `SI-F3-*` | framing: "Maximize your own number of points." |
