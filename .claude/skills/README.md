# Project skills

Claude Code skills for this repo, copied from
[alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills)
at commit `c85b17e` (MIT, see `LICENSE-claude-skills`). All bundled scripts are
Python standard library only, with no network calls or shell-outs.

| Skill | Use it for |
|---|---|
| `statistical-analyst` | Hypothesis tests, confidence intervals, effect sizes (e.g. is the noise-flip effect real?) |
| `agent-regression-evals` | Paired stats over repeated trials, pass@k, flaky cases (LLM players via Ollama) |
| `data-quality-auditor` | Profiling simulation output for missing values and outliers before analysis |
| `research-summarizer` | Summarizing papers and extracting citations |
| `content-humanizer` | Making Substack drafts read less like AI |
| `self-eval` | Honest grading of finished work |

To use them in every Claude session, upload them in claude.ai under
Settings → Capabilities → Skills.
